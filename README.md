# Mission Controller 🚀

Put the controls back where they belong. A lightweight macOS utility that overlays instant, responsive window management controls (Close/Force-Quit, Minimize, and Quit) directly onto your native Mission Control previews.

---

### What's New
* **Smart Force-Quit:** Clicking the close button completely terminates the target process for that window—safeguarded with a built-in safety check so it won't accidentally nuke your last remaining instance.
* **Factory-Clean Alignment:** Meticulously re-aligned the 3-icon cluster so the layout looks and feels completely native to macOS.

---

### Quick Installation

1. Grab the latest `Mission Controller.zip` from the [Releases](../../releases) page.
2. Extract the archive and drag **Mission Controller.app** into your **Applications** folder.
3. Launch it and grant **Accessibility permissions** when prompted so it can read and interact with the window layers.

> **First-time macOS tip:** If Gatekeeper gives you a warning on first launch, just right-click (or Control-click) the app icon, select **Open**, and click **Open** in the dialog prompt.
